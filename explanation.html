Rows follow token positions 0 and 1. Display values are rounded to four decimal places. “masked” means −∞ before softmax, giving exactly zero attention weight.

Fixed weights ≠ fixed queries.

The matrices stay fixed in this exercise. A query is still computed from a token’s input. “river” at position 0 starts as [1, 0]; at position 1 it starts as [1.25, −0.25]. Its query therefore changes from [0] to [−0.25].

Order enters in two different ways.

Position vectors encode where a token occurs. A causal mask reveals which tokens it may read. With both switches off, swapping the words simply reorders the outputs. With the causal mask on, swapping can change the outputs even without position vectors.

The model’s complete fixed parameters
Word embeddings:  river = [1, 0]      bank = [0, 1]
Position vectors: position 0 = [0, 0]  position 1 = [0.25, -0.25]

W_Q = [[0], [1]]                 → query selects coordinate 2
W_K = [[1], [0]]                 → key selects coordinate 1
W_V = [[1, 0], [0, 1]]           → values keep both coordinates
W_O = [[1, 0], [0, 1]]           → output projection is the identity

Query/key dimension = 1, so the score divisor √1 is 1.
The two embedding coordinates are artificial numbers, not named meanings.
05 /

The next concrete task.

Add one operation

Layer normalization.

For each token separately, find the mean and variance across its vector’s coordinates. Center the coordinates around zero, then scale by the standard deviation.

μ = mean(x)
variance = mean((x − μ)²)
normalized = γ × (x − μ) / √(variance + ε) + β

A simple teaching choice is γ = 1 and β = 0. For the current first-token result [2, 0], the mean is 1 and variance is 1, so the result is [1, −1] / √(1 + ε). A small positive ε prevents division by zero. This operation is planned; it is not in the model yet.

  1. Add normalization and expose its values.Return mean, variance, and normalized output in the trace. Check the result against one hand calculation and a constant vector.
  2. Add a tiny feed-forward network.One linear transform, a simple activation, and another linear transform, applied separately to each token.
  3. Add the second skip and normalization.Add the feed-forward result to its input, then normalize again.
  4. Produce next-token probabilities.Project each token’s final vector into vocabulary scores, then apply a new softmax across the vocabulary.
  5. Finish the walkthrough, then build training.Verify a full forward pass by hand. Start the separate PyTorch exercise only after this example is complete.
Two softmax operations, two jobs. Attention softmax distributes weight across input tokens. The future vocabulary softmax distributes probability across possible next tokens. The first is already implemented; the second is still missing.
